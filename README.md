# 大学英语四级核心词汇

一个无需后端、开箱即用的大学英语四级核心词汇浏览网页。项目把 456 个词条整理为 7 个 List，支持搜索、词性筛选、随机单词、问答对战（含联机对战）、收藏、练习模式、真人发音和例句搭配展开，适合用于日常背词、快速查词和自测。

## 功能

| 功能 | 说明 |
| --- | --- |
| 分 List 浏览 | 可在全部词汇和 List 1-7 之间快速切换 |
| 中英文搜索 | 可搜索英文单词、中文释义或序号 |
| 词性筛选 | 支持名词、动词、形容词、副词等词性分类 |
| 随机单词 | 从当前 List 或筛选结果中随机抽取单词；每轮不重复，可把没记住的词留到下一轮复习 |
| 问答对战 | 用当前词汇范围做四选一问答，支持人机对战、同屏双人和无需后端的联机对战，每题限时 15 秒 |
| 真人发音 | 每个词条都有美式/英式真人录音，点击喇叭按钮即可朗读 |
| 音标显示 | 456 个词条全部带 IPA 音标，随美音/英音切换 |
| 例句搭配 | 每个词条可展开同义词、常用搭配和双语例句，例句也能点读 |
| 收藏生词 | 使用本地浏览器存储收藏状态，无需登录 |
| 练习模式 | 可独立遮住英文单词或中文释义，点击词条逐条查看 |
| 听音辨词 | 遮住单词后朗读按钮仍然可用，可配合「点击即读」做听写练习 |
| 响应式布局 | 同时适配电脑、平板和手机 |
| 无需构建 | 原生 HTML、CSS 和 JavaScript，下载即用 |

> **关于词条重复**：这 456 条词目实际由 436 个不重复单词构成。第 7 组里混有 20 个复习词，与前面各组重复，释义保持一致；它们在「全部词汇」中会再次出现，便于按 List 复习。

## 随机单词说明

随机抽词使用「洗牌袋」而不是每次独立随机：

- 打开随机单词时，会把当前 List 或筛选结果打乱成本轮队列，然后逐个抽出；**同一轮里每个词条最多出现一次**，抽完才重新洗牌。
- 弹窗里的「遗忘」按钮会把当前词条留到下一轮；再点一次可以取消。
- 一轮抽完后，如果本轮标记过「遗忘」，点「下一轮」只会抽这些词；如果没标记，就重新洗牌全部候选词。
- 复习轮里继续标记「遗忘」，会留到再下一轮，直到没有标记为止。
- 待复习词条只属于当前这一轮；切换 List、搜索词、词性或收藏筛选会重新开始一轮，并清空尚未开始的遗忘队列（页面会提示）。
- 弹窗顶部会显示当前轮次和进度；只有 1 个候选词且在第一轮时不显示进度。
- 关闭弹窗再打开不会重置本轮进度或遗忘标记（除非候选集合发生变化），因此可以放心关掉再继续抽。
- 新一轮的第一个词会避开上一轮的最后一个词，避免跨轮连续重复。

## 问答对战说明

点击标题栏右上角的「问答对战」按钮，即可用当前 List、搜索词、词性或收藏筛选结果出题。

- **三种模式**：
  - **人机对战**：你和电脑各答同一道题，每题 15 秒，电脑约有 65% 的概率答对；双方答对一题各得 1 分。
  - **同屏双人**：两位玩家共用一台设备。玩家 1 先答，提交后进入交接页，遮挡题目和玩家 1 的答案；玩家 2 拿到设备后重新计时 15 秒作答。两人都答完后才公布正确答案和各自得分。
  - **联机对战**：通过邀请码和应答码建立点对点连接，双方在各自设备上同时回答同一道题；详见下方「联机对战说明」。
- **出题规则**：题目在「英文选中文」和「中文选英文」之间混合，四个选项，干扰项优先从当前范围中取；同一个单词不会在同一局里重复出题。
- **题数**：可选 5 / 10 / 15 题，默认 10 题；如果当前范围的去重单词不足所选题数，会按实际可出题数量开始。至少需要 4 个不重复单词才能进入对战。
- **操作**：点击选项或按键盘 `1`-`4` 作答；答完一题点「下一题」，全部结束后显示胜者、比分和正确率，可「再来一局」或返回设置。
- **计时**：每题 15 秒，超时按未作答处理，不计分；倒计时条和秒数变红表示剩余 5 秒以内。
- **作答反馈**：每题结束后公布正确答案，并展示单词、音标、词性、释义和第一条例句，可点击喇叭朗读。
- **双人交接**：交接页会遮挡题目，避免玩家 2 提前看到；玩家 2 的选项顺序会重新打乱。

## 联机对战说明

联机对战不需要后端服务器：双方浏览器通过 WebRTC DataChannel 点对点直连，题目和答案由房主浏览器生成并同步。

- **进入方式**：在「问答对战」中选择第三张模式卡「联机对战」。
- **创建房间**：房主点「创建房间」，生成邀请码；把邀请码复制到微信/QQ 等聊天工具发给对手。
- **加入房间**：对手点「加入房间」，粘贴邀请码，生成应答码，再把应答码发回房主。
- **完成连接**：房主把收到的应答码粘贴到「粘贴对手返回的应答码」，点「完成连接」。双方状态显示已连接后，房主选择题数并开始。
- **对战规则**：双方同时回答同一道题，每题 15 秒；由房主统一揭晓答案、计分和切换下一题。至少需要 4 个不重复单词。
- **再来一局**：联机对战的「再来一局」由房主发起，对手端显示「等待房主」。
- **房间编号**：只用于标识本次房间；**不能只凭编号加入**，加入必须使用邀请码。
- **邀请码较长**：邀请码和应答码是完整的 WebRTC 会话描述（SDP），通常约 1KB，无法压缩成 6 位短房间号；发送时请作为一整段文本复制粘贴，不要截断或分行。
- **网络限制**：目前只配置了公共 STUN，没有 TURN 中继。同一 Wi-Fi、普通家庭网络通常可以直连；公司网络、对称 NAT、部分移动网络可能连不上。
- **断线行为**：房主退出或断网，房间立即结束；刷新页面也会丢失房间，需要重新创建。
- **公平性**：题目和正确答案在房主浏览器中生成，房主端理论上能看到答案；适合熟人之间的休闲对战。
- **浏览器要求**：双方都需要支持 WebRTC 的现代浏览器；正式部署建议使用 HTTPS。

## 发音功能说明

- **真人音频**：音频取自有道词典的公开发音接口，按美式/英式分别请求，不是机器合成音。
- **需要联网**：播放发音时才会下载对应音频，**其余功能（浏览、搜索、筛选、收藏、练习模式、例句文字）完全离线可用**。
- **按需加载**：只有滚动到视口附近的词条才会预取音频，不会一次性请求 456 个文件；已播放过的音频会在内存中缓存，重复点击不再请求。
- **口音切换**：右下角「英语发音」区域的按钮可在美音（US）和英音（UK）之间切换，音标和朗读都会同步切换，选择会记在本机浏览器中。
- **点击即读**：开启后点击词条任意位置即可朗读。
- **整句朗读**：常用搭配和例句都可以点击朗读（接口同样支持整句）。
- **自动降级**：在线音频加载失败时会自动改用浏览器内置语音朗读，并给出提示。

> 首次直接双击 `index.html` 打开时，部分浏览器会限制本地文件联网，导致发音无法播放。此时请改用本地服务器打开（见下文）。

## 例句搭配说明

点击释义右侧的 `⌄` 按钮即可展开该词条的语料：

- **同义词**：按词性分组，帮助建立词义网络。
- **常用搭配**：如 `search and rescue = 搜索与营救`，比孤立背单词更实用。
- **例句**：英文 + 中文对照，可用于体会语境和用法。

右下角「例句搭配」区域提供两个开关：

- **展开例句**：一次性展开所有词条（适合集中阅读，词条较多时页面会很长）。
- **全部收起**：一键收起所有已展开的词条。

语料按「单词」存放（见下文数据格式），所以同一个单词的不同词条显示的是同一份语料，这正是用来对照它们释义差异的依据。

## 直接使用

下载项目后，直接打开以下文件即可：

```text
网页版单词表/index.html
```

Windows 也可以在项目根目录执行：

```powershell
start .\网页版单词表\index.html
```

如果希望通过本地服务器访问（推荐，发音功能更稳定）：

```bash
python -m http.server 8000 --directory 网页版单词表
```

然后访问：

```text
http://localhost:8000
```

## 数据格式

网页数据保存在 `网页版单词表/words.js`，包含两个赋值语句。

第一个是词条数组，共 456 条：

```javascript
window.CET4_WORDS = [
  {
    "list": 1,
    "number": 1,
    "word": "eloquent",
    "part": "adj.",
    "meaning": "雄辩的；有说服力的",
    "usphone": "ˈeləkwənt",
    "ukphone": "ˈeləkwənt",
  },
  // ...
];
```

- `usphone`：美式音标，用于「美音」模式显示。
- `ukphone`：英式音标，用于「英音」模式显示。
- 两个字段都可以留空，此时音标位置显示 `—`，发音功能不受影响。

第二个是按「单词」存放的语料表：

```javascript
window.CET4_WORD_DETAILS = {
  "eloquent": {
    "sentences": [{ "en": "He's very intelligent and eloquent.", "cn": "他很聪明，口才也很好。" }],
    "phrases": [],
    "synonyms": [{ "pos": "adj.", "words": ["meaningful", "moving"], "cn": "有说服力的；动人的" }],
  },
  // ...
};
```

- `sentences`：双语例句，点击可朗读。
- `phrases`：常用搭配，点击可朗读。
- `synonyms`：按词性分组的同义词。
- 三个字段都可以缺省，缺省的区块不会显示，展开按钮也会自动隐藏。

**为什么语料要单独建表**：语料按单词存放，同一单词的多条词目共用一份内容；456 条词目只对应 436 个不重复单词，重复的 20 条也不会把例句存两遍。这样 `words.js` 更小，替换词库时也只需要重建这一张表。

修改或替换这两个结构，即可使用自己的词库。

### 重新生成音标与语料

音标和语料都是预先抓取好写进 `words.js` 的，网页运行时不查询这些接口。如果替换了词库，可以按下面的顺序重新生成：

```bash
cd 网页版单词表
python tools/import-xlsx.py "F:/path/to/单词表.xlsx"   # Excel -> tools/xlsx-words.json
node tools/build-words.js                              # 生成基础 words.js（音标先用 Excel 里的）
node tools/fetch-phonetics.js                          # 抓取缺失单词的音标 -> tools/phonetics.json
node tools/fetch-details.js                            # 抓取例句/搭配/同义词 -> tools/details.json
node tools/build-words.js                              # 合并音标和语料，重建 words.js
```

- `import-xlsx.py` 读取「第N组」分块和「单词 / 音标 / 词性 / 中文意思」表头，分组编号会写成 List 编号。
- 两个抓取脚本都只处理去重后的单词（当前词库 456 条中有 436 个不重复单词），需要联网。
- 两个抓取脚本都支持增量运行，加了 `--force` 可强制全部重抓。
- `build-words.js` 可重复运行，不会重复叠加数据；抓取失败时会回退到 Excel 里的音标。

改完数据后可以跑一次自检（检查词条完整性、音标与语料覆盖、HTML 标签闭合）：

```bash
node tools/check.js
```

## 发布到 GitHub

在项目根目录执行：

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

仓库上传后，在 GitHub 页面打开：

```text
Settings -> Pages -> Build and deployment -> Source
```

选择 `GitHub Actions`，然后添加以下工作流文件：

```text
.github/workflows/deploy-pages.yml
```

工作流内容：

```yaml
name: Deploy static site to Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Pages
        uses: actions/configure-pages@v5

      - name: Upload site
        uses: actions/upload-pages-artifact@v3
        with:
          path: "./网页版单词表"

      - name: Deploy
        id: deployment
        uses: actions/deploy-pages@v4
```

推送后等待 Actions 执行完成，即可通过 GitHub Pages 提供的网址访问。

## 自定义

- 修改 `网页版单词表/styles.css` 中的 `:root` 变量可调整配色和视觉样式，单词表的列宽也在这里（`--col-*` 变量，窄屏会在媒体查询中覆写）。
- 修改 `网页版单词表/app.js` 可调整筛选、收藏、练习模式、发音和例句展开逻辑。
- 修改 `网页版单词表/words.js` 可替换或扩充词汇数据（含音标与语料）。
- 收藏记录保存在浏览器的 `cet4-favorites` 本地存储项中。
- 发音口音保存在 `cet4-accent`，点击即读开关保存在 `cet4-auto-speak`，全局展开例句开关保存在 `cet4-detail`。
- 音频接口地址在 `app.js` 顶部的 `audioBase` 常量处，默认使用有道词典的公开音频接口（该接口也支持整句朗读）。

## 浏览器兼容性

推荐使用近期版本的 Chrome、Edge、Firefox 或 Safari。项目使用原生 HTML、CSS 和 JavaScript，不需要构建步骤。

发音功能依赖 `<audio>` 与 `IntersectionObserver`，在以上浏览器中均可正常工作。若需播放失败时的降级行为，还依赖 `speechSynthesis`（浏览器内置语音合成）。
